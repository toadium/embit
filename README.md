## 二、Embit 开源仓库 README 完整正文（可直接粘贴使用）

# Embit
> 轻量内核，全栈具身 —— 基于MoonBit的下一代通用具身机器人开发框架






## 项目简介
Embit 是全球首个完全基于 MoonBit 语言构建的通用具身智能机器人全栈开发框架，打通「动力学仿真—多模态感知—VLA推理—运动控制—真机部署」完整技术链路，为机器人研发提供一套无Python依赖、高实时性、内存安全、跨硬件部署的新一代技术底座。

框架采用分层解耦设计，既具备端侧轻量化部署的核心优势，也完全兼容中大规模具身大模型的工作站级训练与推理，可快速适配人形机器人、四足机器人、协作机械臂、轮式移动机器人等全品类形态，兼顾科研算法迭代效率与工业落地稳定性。

## 核心特性
- 🚀 **全链路原生MoonBit实现**：从仿真交互、推理调度到运动控制统一基于MoonBit开发，静态编译单文件部署，彻底摆脱Python依赖地狱，运行性能接近原生C
- 🤖 **通用机器人抽象层**：基于URDF标准设计，配置化适配多形态机器人，一次开发跨机型复用，无需重复造轮子
- 🧠 **全尺度VLA推理兼容**：基于ggml/vla.cpp构建，支持从1B端侧轻量模型到70B+通用具身大模型，覆盖INT4~FP16全精度，CPU/GPU/嵌入式多硬件统一调度
- ⚡ **高实时性控制运行时**：依托MoonBit结构化并发与内存安全特性，实现微秒级控制环路抖动，满足机器人高频实时控制需求
- 🔌 **仿真与真机无缝切换**：统一硬件抽象接口，同一套控制代码可直接运行于Ignition Gazebo仿真环境与实体嵌入式机器人，Sim2Real迁移成本极低
- 🎛️ **内置可视化调试工具**：基于Selene引擎打造监控面板，支持实时状态观测、数据回放、参数在线调优，大幅提升开发调试效率

## 快速开始
### 环境要求
- MoonBit 工具链 >= 0.10.0
- Ignition Gazebo Fortress / Harmonic
- （可选）支持CUDA的GPU设备，用于大模型加速推理

### 安装
​```bash
# 添加核心依赖到你的 MoonBit 项目
moon add embit/embit-core
moon add embit/embit-gazebo
moon add embit/embit-ggml
```

### 最小示例：控制仿真机器人接收VLA指令
```moonbit
fn main() {
  // 1. 连接仿真环境
  let robot = GazeboRobot::connect("t800")?
  // 2. 加载VLA行动模型
  let model = VlaModel::load("models/smolvla-7b-q4.gguf")?
  // 3. 获取视觉观测 + 语言指令
  let image = robot.get_camera_image()
  let command = "走到桌子旁边拿起水杯"
  // 4. 推理生成动作序列并执行
  let actions = model.infer(image, command)
  robot.execute_actions(actions)
}
```

## 子模块说明
1. **embit-core**：核心基础库，定义通用机器人接口、数据结构、工具函数，是所有上层模块的共同依赖
2. **embit-gazebo**：Ignition Gazebo 仿真通信SDK，基于Ignition Transport实现标准化话题通信与仿真控制
3. **embit-ggml**：全尺度VLA推理SDK，封装ggml/vla.cpp，提供统一的多模态推理接口
4. **embit-control**：通用运动控制框架，内置机器人抽象层、运动学解算、安全保护模块
5. **embit-view**：基于Selene的可视化调试面板，支持实时监控、数据回放、参数调优
6. **embit-examples**：多场景示例工程，包含人形、四足、机械臂三类典型具身任务Demo

## 三、品牌故事 & 项目愿景（申报书/宣传通用）
### Embit 的诞生
在具身智能与机器人产业爆发的今天，绝大多数研发团队都被束缚在Python技术栈的固有瓶颈里：实时控制的延迟抖动、臃肿的依赖链、嵌入式部署的高成本、真机运行的稳定性隐患……而Rust等替代方案又带来陡峭的学习曲线与极低的迭代效率。

我们始终相信，新一代的机器人，应该配得上新一代的开发语言。

随着国产系统编程语言MoonBit走向成熟，静态编译、内存安全、结构化并发、极速编译、跨平台部署的特性，恰好命中了机器人控制领域的核心痛点。Embit 由此而生：我们选择以MoonBit为唯一顶层语言，从零搭建一套完整的具身智能全栈框架，让机器人开发摆脱对Python的路径依赖，兼顾高性能、高可靠性与高效的开发迭代体验。

Embit 的名字，是 Embodied 与 Bit 的融合——我们希望用最精简的数字内核，承载最完整的具身智能，让每一台机器人都能拥有稳定、高效、安全的智能大脑。

### 我们的愿景
成为下一代通用具身机器人的标准开发基座，让高性能具身智能不再是大厂与高端实验室的专属，让中小团队、高校实验室、创业者都能以极低的门槛，快速完成机器人智能算法的研发、验证与落地。

我们不止于打造一个工具框架，更希望推动国产编程语言在高端工业与机器人领域的深度落地，构建自主可控的具身智能技术生态。
