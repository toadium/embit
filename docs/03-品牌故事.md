# Embit 品牌故事

## 1. 项目名称

**正式名称**：Embit
**英文全称**：Embit Embodied Robot Framework
**中文定名**：桂枢 通用具身机器人开发框架

**备选名称**（供参考，最终采用 Embit）：

| 备选名 | 含义 | 推荐理由 |
|--------|------|----------|
| Embot | Embodied + Robot | 简洁直观，但已有同名开源项目，存在商标冲突风险 |
| MoonBot | MoonBit + Robot | 突出 MoonBit 生态关联，但泛化能力弱，限制未来扩展 |
| BitBot | Bit + Robot | 发音顺口，但技术属性不如 Embit 明确 |

**最终确认**：Embit（桂枢）—— 兼顾技术含义、品牌绑定与国际化传播。

## 2. 命名理由

Embit 由 "Embodied"（具身智能）与 "Bit"（二进制/算力）组合而成：

- **Embodied**：直指项目核心——具身智能（Embodied AI），即智能体通过与物理环境交互获得认知与行动能力，这是当代机器人研究最前沿的方向。
- **Bit**：代表二进制与数字算力，既呼应 MoonBit 技术底座（MoonBit 语言名中的 "Bit"），又传达"以数字智能驱动物理世界"的理念。
- **整体含义**：用最精简的数字内核，承载最完整的具身智能。名称简短有力，技术属性明确，中英文发音均顺口易记，适合国际化传播。

## 3. 品牌故事

在具身智能与机器人产业爆发的今天，绝大多数研发团队都被束缚在 Python 技术栈的固有瓶颈里：实时控制的延迟抖动、臃肿的依赖链、嵌入式部署的高成本、真机运行的稳定性隐患……而 Rust 等替代方案又带来陡峭的学习曲线与极低的迭代效率。

我们始终相信，新一代的机器人，应该配得上新一代的开发语言。

随着国产系统编程语言 MoonBit 走向成熟，静态编译、内存安全、结构化并发、极速编译、跨平台部署的特性，恰好命中了机器人控制领域的核心痛点。Embit 由此而生：我们选择以 MoonBit 为唯一顶层语言，从零搭建一套完整的具身智能全栈框架，让机器人开发摆脱对 Python 的路径依赖，兼顾高性能、高可靠性与高效的开发迭代体验。

Embit 的名字，是 Embodied 与 Bit 的融合——我们希望用最精简的数字内核，承载最完整的具身智能，让每一台机器人都拥有稳定、高效、安全的智能大脑。

我们的愿景是成为下一代通用具身机器人的标准开发基座，让高性能具身智能不再是大厂与高端实验室的专属，让中小团队、高校实验室、创业者都能以极低的门槛，快速完成机器人智能算法的研发、验证与落地。

## 4. 定位与口号

**一句话定位**：
Embit 是基于 MoonBit 的通用具身智能机器人全栈开发框架，打通「动力学仿真—多模态感知—VLA推理—运动控制—真机部署」完整技术链路。

**核心 Slogan**：
轻量内核，全栈具身 —— 基于 MoonBit 的下一代机器人智能开发框架

**英文 Slogan**（可选）：
Lightweight Core, Full-Stack Embodiment — The Next-Gen Robot Framework Powered by MoonBit

## 5. 品牌价值观

| **自主可控** | 以国产 MoonBit 语言为底座，构建自主可控的具身智能技术栈，减少对外部技术生态的路径依赖 |
| **极简高效** | 从 0 到 1 搭建完整框架，拒绝堆砌，以最小可用内核承载最大功能覆盖 |
| **开放协作** | 全部代码 Apache License 2.0 开源，欢迎社区贡献，共同推进 MoonBit 在机器人领域落地 |
| **性能优先** | 以接近原生 C 的运行时性能为标准，确保实时控制场景下的低延迟与高确定性 |
| **友好普惠** | 降低具身智能研发门槛，让高校、中小团队、创业者都能平等地参与下一代机器人创新 |
