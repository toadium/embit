## 4. 性能特征分析

### 4.1 算法复杂度

| 操作 | 复杂度 | 说明 |
|------|--------|------|
| 轨迹规划（N 关节，T 步） | O(N × T) | 线性于关节数与时间步数 |
| PID 更新 | O(1) | 常数时间 |
| 阻抗控制更新 | O(1) | 常数时间 |
| 传感器融合更新 | O(1) | 常数时间 |
| IK/FK 解算（6-DOF） | O(1) | 简化解算器为常数时间 |
| 关节组批量设置（N 关节） | O(N) | 线性于关节数 |

### 4.2 内存特征

| 数据结构 | 内存占用 | 说明 |
|----------|----------|------|
| Trajectory | O(N × T) | 路径点数组 |
| JointGroup | O(N) | 关节名 + 位置 Map |
| CartesianTrajectory | O(W) | 路径点数组 |
| SensorFusion | O(1) | 固定大小状态 |
| PIDController | O(1) | 固定大小状态 |

## 5. 后续优化方向

1. **真实 FFI 性能测量**：启用条件编译（`EMBIT_HAS_IGNITION` / `EMBIT_HAS_GGML` / `EMBIT_HAS_SELENE`）后，测量端到端延迟
2. **控制环路抖动分析**：利用 `ControlLoopBenchmark` 在实时操作系统上测量控制环路抖动分布（P50/P99）
3. **内存分配优化**：轨迹规划中的数组分配可预分配复用
4. **并行化**：批量推理（batch_infer）可并行化各组推理任务
5. **SIMD 优化**：张量运算可利用 MoonBit native 后端的 SIMD 指令
